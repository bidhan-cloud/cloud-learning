# NSLOOKUP

## What is nslookup?
nslookup checks DNS and resolves domain names to IP addresses.

## Examples

nslookup google.com
Shows google IP address.

nslookup github.com
Shows github IP address.

nslookup this-domain-should-not-exist-12345.com
Returns NXDOMAIN (domain not found).

## Cloud Thinking
Used to test if DNS is working.
